# 论文格式与风格仿写指南（Format & Style Mimicry）

> 用途：当用户提供**一篇参考英文论文**（`.tex` / `.pdf` / `.md` / 纯文本）+ **一篇中文论文或草稿**时，不仅完成中译英与学术润色，还完整仿写参考论文的**排版格式、章节骨架、LaTeX/Markdown 规范与行文风格**。

---

## 红线（防抄袭与内容忠实）
1. **只仿结构与格式，绝不照搬内容**：严禁复制参考论文的原句、观点、实验数据、图表内容或文献列表。
2. **不编造缺失部分**：若参考论文有某小节（如 *Broader Impact*、*Ablation Study*）而中文稿没有，**只保留带 `% TODO: 请补充...` 注释的占位小节**，绝不虚构内容。
3. **保留中文稿的所有事实**：数字、公式、模型名、引用、结论强度全部忠实于中文稿。

---

## 第一步：从参考论文提取「格式蓝图」（内部完成）

先通读参考论文，提取以下 6 个维度的特征，并在输出开头用简明表格向用户展示：

| 维度 | 需要提取的细节 |
|---|---|
| **1. 载体与模板** | 文档格式（LaTeX / Markdown / Word 纯文本）；若为 LaTeX，记录 `\documentclass`（如 `IEEEtran`、`cvpr`、`neurips_2024`、`elsarticle`、`llncs`）、单/双栏、导言区关键宏包、Title/Author/Keywords 写法 |
| **2. 章节骨架** | 一/二/三级标题层级与编号风格（`I. INTRODUCTION` 全大写罗马数字 vs `1. Introduction` 阿拉伯数字）、标题大小写（Title Case vs Sentence case）、是否使用 `\paragraph{Heading.}` 段首加粗小标题 |
| **3. 摘要与引言范式** | 摘要字数与结构（背景-问题-方法-结果）；引言末尾是否用 bullet 列表陈述贡献（如 *Our main contributions are summarized as follows:*），或用段落陈述；是否包含论文结构导览段（*The remainder of this paper is organized as follows...*） |
| **4. 图表与公式规范** | 编号与缩写风格（`Fig.~\ref{}` vs `Figure~\ref{}`，`Tab.` vs `Table`，`Eq.~()` vs `Equation`）；表题在表上/图题在图下；三线表（`\toprule / \midrule / \bottomrule`）或 IEEE 表格；行内/行间公式符号风格（向量 `\mathbf{x}`、矩阵 `\mathbf{X}`、集合 `\mathcal{X}`） |
| **5. 引用与文献风格** | 数字引用 `\cite{}`（IEEE/CVPR）vs 作者-年份 `\citep{}`/`\citet{}`（ACL/NeurIPS/JMLR）；句末标点与引用位置（`... method~\cite{a}.`） |
| **6. 行文微风格** | 人称倾向（主动 `We propose` vs 被动 `is proposed`）；实验部分时态（一般现在时 vs 一般过去时）；句长节奏与衔接词密度 |

---

## 第二步：章节映射与排版仿写

1. **章节对齐**：把中文稿的章节对应到参考论文的骨架上。若结构不完全一致，保留中文稿的实质内容，同时按参考论文的标题层级、编号和大小写风格重写标题。
2. **翻译与润色**：按 `zh2en_rules.md`、`dl_terminology.md`、`paragraph_logic.md` 和 `retrieve.py` 完成高质量中译英与逻辑调整，同时遵守蓝图中的**人称、时态、句长和衔接风格**。
3. **格式输出对应**：
   - **参考论文是 `.tex`（或用户明确要 LaTeX）**：输出完整可编译的 `.tex` 代码（复用参考论文的 `\documentclass`、导言区排版设置、章节命令、图表/公式环境模板与引用命令，清空参考论文正文，填入翻译润色后的中文稿内容）。
   - **参考论文是 `.pdf`**：先读取 PDF 提取版面与写作特征；询问或默认按目标期刊对应的标准 LaTeX 模板（如 IEEEtran / CVPR / NeurIPS）或结构化 Markdown 输出。
   - **参考论文是 `.md` / 纯文本**：输出完全对齐标题层级、编号、加粗小标题、列表、图表说明与引用格式的 Markdown。
