# 投稿前审稿人视角预审指南（Pre-submission Review）

> 用途：在论文提交给 NeurIPS / ICLR / ICML / CVPR / ICCV / ACL / EMNLP / TPAMI / TIP 等英文顶会或顶刊之前，模拟资深审稿人（Area Chair / Senior Reviewer）进行严格预审，提前排查**逻辑漏洞、过度声称（Overclaim）、实验短板与写作隐患**。
> 硬性原则：**绝不替作者编造实验数据或虚构新实验结果**；对缺失的实验或论据，明确标出“需作者补充的实验/说明”。

---

## 一、五维审查清单

### 维度 1：动机与定位（Motivation & Positioning）
- [ ] 引言前 2 段内是否清晰点出**具体的研究瓶颈**（而非泛泛而谈“深度学习发展很快”）？
- [ ] 现有方法的局限是否**有据可依**（带具体引用或直观反例），而不是空洞批驳“existing methods perform poorly”？
- [ ] 本文的核心洞察（Key Insight）与提出的方法之间是否严丝合缝，不存在“动机讲 A、方法做 B”的割裂？
- [ ] Related Work 每段结尾是否明确说明了与本文的本质区别？

### 维度 2：方法严谨性与可读性（Technical Soundness & Clarity）
- [ ] 符号系统是否前后一致（向量/矩阵/集合大小写与加粗统一，无未定义符号）？
- [ ] 每个模块是否都讲清了“**为什么需要它（Why）** + **怎么算（How）** + **带来什么效果（Effect）**”？
- [ ] 计算复杂度 / 显存开销是否交代清楚？若宣称“lightweight / efficient”，是否给出了参数量、FLOPs 或实际延迟（latency）？
- [ ] 训练阶段与推理阶段的行为差异是否写明？

### 维度 3：过度声称与学术克制（Overclaim & Hedging）
- [ ] 检查绝对化词语：`prove`（无严格数学证明时禁用）、`completely solve`、`always`、`never`、`perfect`、`first`（若写 *first* 需加 *to the best of our knowledge* 且限定准确范围）。
- [ ] 检查 `significantly`：若未做统计显著性检验（如 p-value / 多次随机种子置信区间），改为 `substantially / notably / consistently`。
- [ ] 摘要、引言和结论中的性能提升数字是否与实验表格完全一致？是否存在把“在 1 个数据集上略微提升”夸大为“全面 SOTA”？

### 维度 4：实验公平性与说服力（Experimental Rigor）
- [ ] 基线对比是否公平（同主干网络、同输入分辨率、同数据增强/训练轮次；若不同是否明确说明）？
- [ ] 是否包含**核心消融实验（Ablation Study）**，逐一验证每个新模块与超参数的独立贡献？
- [ ] 对比基线是否够新（是否漏掉近 1–2 年该方向的代表性工作）？
- [ ] 是否报告了随机种子均值/方差或失败案例分析（Failure Cases）？
- [ ] 结论或独立小节是否坦诚讨论了**局限性（Limitations）**？

### 维度 5：写作质量与排版（Writing & Presentation）
- [ ] 先运行 `scripts/audit.py` 扫描中式表达、AI 腔词汇、超长句和被动语态连用。
- [ ] 图注/表注是否 **self-contained**（仅看图表与标题即可理解核心对比与结论）？
- [ ] 缩写首次出现是否给出全称，术语全文是否唯一？

## 二、输出格式（`review` 模式）

```markdown
## 投稿前预审报告（目标档次：<NeurIPS / CVPR / TPAMI / 通用顶会>）

### 1. 综合评分卡（1–5 分）
| 维度 | 评分 | 核心一句话评价 |
|---|---|---|
| 动机与定位 | X/5 | … |
| 方法严谨与清晰度 | X/5 | … |
| 表述克制（防 Overclaim） | X/5 | … |
| 实验完备与公平性 | X/5 | … |
| 语言与写作规范 | X/5 | … |

### 2. 致命/高风险问题（Major Concerns — 审稿人极可能据此拒稿）
1. **[问题类别] 标题**
   - **定位**：第 X 节 / 原句摘录
   - **审稿人视角质疑**：……
   - **修改建议**：给出具体的文字改写方案或建议补充的实验/分析（不编造数据）

### 3. 中低风险与语言问题（Minor Concerns & Overclaim 清单）
| # | 原文摘录 | 问题类型 | 建议改写 |
|---|---|---|---|
| 1 | … | Overclaim / 逻辑跳跃 / 中式表达 / 符号不清 | … |

### 4. 投稿前行动清单（按优先级排序）
- [ ] P0（必改）：……
- [ ] P1（建议补强）：……
- [ ] P2（语言精修）：……
```
