# Introduction 学术句式库（深度学习论文）

> 高频动词（`we + V`）：`propose` / `introduce` / `show` / `present` / `design` / `provide` / `find` / `demonstrate` / `develop` / `evaluate` / `argue` / `aim` / `observe` / `extend`
> 结构（CARS 模型）：背景定位 → 现有局限 → 本文动机与核心思路 → 贡献列表（3 条平行结构）→ 章节导览（期刊可选）。

## 1. 背景引入（简短，1 段内切入）
- *[Task] plays a central role in [applications such as A, B, and C].*
- *Over the past decade, [models] have become the de facto standard for [task] [CITE].*
- *Driven by [factor], recent models have achieved impressive accuracy on [benchmarks].*

## 2. 现有方法不足与研究空白
- *However, these methods typically assume [assumption], which rarely holds in [real setting].*
- *While prior work [CITE] mitigates [issue A], it still suffers from [issue B] due to [reason].*
- *A key bottleneck lies in [specific mechanism]: when [condition], [failure mode occurs].*
- *As a result, there remains a gap between [current capability] and [desired property].*
- *Only a few studies [CITE] have explored [direction], and they do not account for [aspect].*

## 3. 本文动机与核心思想
- *Motivated by this observation, we ask: can we [core research question]?*
- *To address these limitations, we propose **[Name]**, which [high-level mechanism].*
- *Our key insight is that [core intuition], allowing us to [benefit].*
- *In contrast to [prior paradigm] that [old approach], we [new approach] (see Figure [REF]).*
- *To the best of our knowledge, this is the first work to [specific novelty].*（谨慎使用，确保准确）

## 4. 贡献总结（顶会/顶刊标准句式）
- *In summary, our main contributions are as follows:*
- *The main contributions of this work can be summarized as follows:*
  - ***Method / Formulation**: We propose / introduce [Name], a ... that ...*
  - ***Design / Analysis**: We design / establish ..., enabling ... without ...*
  - ***Empirical validation**: We evaluate [Name] on [benchmarks] and show that it outperforms [baselines] by [X].*

## 5. 论文结构导览（期刊常用，顶会常省略）
- *The remainder of this paper is organized as follows. Section 2 reviews related work. Section 3 details the proposed framework. Section 4 presents experimental results, and Section 5 concludes the paper.*
