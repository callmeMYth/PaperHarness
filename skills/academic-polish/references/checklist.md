# 终稿自检清单

输出终稿前逐项核对，任何一项不通过都要回到对应步骤修正。

## 内容忠实（红线）
- [ ] 所有数字、单位、百分比、数据集名、模型名与原文一致
- [ ] 结论强度未被放大（"有所提升"未变成 "significantly outperforms"）
- [ ] 未新增原文没有的论点、实验或引用
- [ ] `\cite{}`、`\ref{}`、`$...$`、`\label{}` 等 LaTeX 命令原样保留，位置合理
- [ ] 未编造参考文献

## 术语
- [ ] 同一概念全文同一译名（对照 `dl_terminology.md` 与用户术语表）
- [ ] 缩写首次出现有全称

## 语言
- [ ] 无流水句；单句 ≤ 40 词
- [ ] 冠词、单复数、主谓一致、时态统一
- [ ] 无口语词、缩写形式（don't / it's）
- [ ] 无 AI 腔高频词堆叠（delve, pivotal, intricate, showcase, underscore…）
- [ ] 每段修饰性副词 ≤ 1 个
- [ ] 连续句子开头不重复

## 逻辑
- [ ] 每段有明确主题句
- [ ] 句间逻辑关系显式（因果/转折/递进）
- [ ] 段落调整均已在对照表中说明理由

## 格式
- [ ] 对照表覆盖每一处修改
- [ ] 终稿可直接粘贴（不含批注标记）
